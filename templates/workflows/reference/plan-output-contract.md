# Plan output contract

Write one Markdown plan per task. Use `PLAN.md` for one task and
`PLAN-<slug>.md` for multiple tasks. Every file has exactly one H1 conventional
commit title, then `## Complexity` with one of `easy`, `medium`, `complex`, or
`very_complex`, followed by sufficient context, numbered or checkable tasks,
and a test plan. Add `## Base Branch` with one branch name only when the task
must target a non-default base. Plans describe implementation; they do not
perform it.
