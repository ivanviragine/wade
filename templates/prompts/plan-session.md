# Goal

Plan a feature: break it into one or more GitHub issues and write a plan file for
each to {plan_dir}/ (one file per issue). You won't create the issues or
implement the feature — after you exit, wade reads the plan files and creates the
issue(s) and draft PR(s) automatically.
