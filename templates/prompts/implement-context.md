# Managed implementation session

Read `.wade/session/WORKFLOW.md` first. It is authoritative for lifecycle,
safety, fixed review, documentation, synchronization, and completion. Then read
each WORK methodology `SKILL.md` listed there. The REVIEW skills named in the
workflow are loaded only by its bounded review step. Read
`.wade/session/AVAILABLE_SKILLS.md` only for optional on-demand project methods.
If any skill conflicts with the workflow, the workflow wins.

Implement `PLAN.md` for issue #{issue_number}: {issue_title}. If no plan exists,
use the issue context supplied above. Keep the fixed workflow steps intact even
when custom skills are active.
